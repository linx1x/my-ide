# Solar system textures

Textures are from [SoumyaEXE/3d-Solar-System-ThreeJS](https://github.com/SoumyaEXE/3d-Solar-System-ThreeJS).

**To populate:** Clone that repo and copy its `public/textures/` contents here:

```bash
git clone --depth 1 https://github.com/SoumyaEXE/3d-Solar-System-ThreeJS.git /tmp/solar-ref
cp -r /tmp/solar-ref/public/textures/* .
```

Or on Windows (PowerShell): clone the repo, then copy the contents of `public/textures` into this folder.

**Required files:** 8k_stars.jpg, stars.jpg, sun.jpg, lensflare0.png, lensflare2.png, mercury.jpg, venus.jpg, earth.jpg, mars.jpg, jupiter.jpg, saturn.jpg, saturn_ring.png, uranus.jpg, neptune.jpg.
